# Hook para Reels (visual + texto + audio)

Lee `docs/02-cada-punto-mejorado.md` sección 1 como referencia.

## Qué entregar
Para el producto/idea que dé el usuario, entrega **5 hooks distintos**, cada uno de un tipo diferente (curiosidad, contradicción, comparación, resultado/prueba, pregunta, POV, error, lista). Para cada uno:

1. **Visual (frame 1):** acción concreta con movimiento, producto en primer plano. Nunca logo, saludo ni pantalla quieta.
2. **Texto en pantalla:** 5–10 palabras, resultado o tensión primero.
3. **Voz (primera frase):** ≤12 palabras, coincide con el texto.
4. **Sonido del frame 1:** golpe, crack, chasquido, o voz directa; música baja.
5. **Por qué funciona:** una línea.

## Reglas
- Español colombiano natural, tuteo.
- No prometer nada falso del producto (originalidad, materiales, garantía). Si falta un dato, déjalo en [corchetes].
- Termina recomendando probar 3 de los 5 como Trial Reels y medir retención al segundo 3 y tasa de salto.
